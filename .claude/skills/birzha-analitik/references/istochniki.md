# Каталог источников — рынок РФ

Правило: **первоисточник бьёт агрегатор.** Ключевые цифры (цена, дивиденды,
отчётность) сверяй с первоисточником, даже если удобно взять из агрегатора.

## Первоисточники (высшее доверие)

| Источник | URL | Что берём |
|---|---|---|
| MOEX ISS API | `iss.moex.com/iss` | Котировка, история, объём, ISIN, лот, уровень листинга, дивиденды, ОФЗ. Тянется `scripts/moex_fetch.py`. |
| MOEX (сайт) | `moex.com` | Карточка бумаги, режимы торгов, индексы (IMOEX, MOEXOG и др.), календарь. |
| e-disclosure.ru | `e-disclosure.ru` | Обязательное раскрытие эмитентов (Интерфакс ЦРКИ): отчётность, существенные факты, решения СД по дивидендам. |
| Сайт эмитента, раздел «Инвесторам/Акционерам» | — | Первоисточник отчётности МСФО/РСБУ, презентаций, дивполитики. |
| ЦБ РФ | `cbr.ru` | Ключевая ставка, доходности ОФЗ, макро. Безрисковый ориентир (Шаг 6). |
| Минфин | `minfin.gov.ru` | Аукционы и параметры ОФЗ. |

## Агрегаторы (вторично — помечать как вторичное)

| Источник | URL | Что удобно | Осторожно |
|---|---|---|---|
| Smart-Lab | `smart-lab.ru` | Свод мультипликаторов, история дивидендов, отчётности в одном месте | Данные могут отставать/содержать ошибки — сверяй |
| Dohod.ru | `dohod.ru` | Дивидендный календарь, индекс стабильности дивидендов | Прогноз, не факт |
| БКС Экспресс / Финам / Тинькофф Пульс | — | Аналитика, таргеты | Мнение брокера ≠ факт; у брокера может быть конфликт интереса |
| РБК Инвестиции, Интерфакс | `rbc.ru`, `interfax.ru` | Новости, существенные факты | Новость проверяй по e-disclosure |

## Брокерские данные (для карточки сделки)

- **Финам:** доступность бумаги, тариф/комиссия, режим (в т.ч. квал-статус), ИИС.
- **Тинькофф Инвестиции:** то же; учитывай, что перечень бумаг и статус «только
  для квалов» на двух брокерах могут отличаться — проверяй оба.

## Egress в облачной сессии

Под egress-политикой организации `iss.moex.com` и `cbr.ru` могут отвечать 403
(заблокированы прокси). Это не ошибка сети — это запрет, обходить нельзя.
Тогда: `moex_fetch.py` запускать на машине пользователя; в сессии — `WebSearch`
по вторичным источникам, с честной пометкой первоисточника как недостижимого.

## Поисковые приёмы (WebSearch, US-only индекс)

- Дублируй запрос на русском и английском: «Сбербанк дивиденды 2026» и
  «Sberbank dividends 2026».
- Тикер + `smart-lab.ru` / `e-disclosure` / `МСФО` сужает выдачу к нужному.
- Для санкций: тикер эмитента + `SDN list` / `OFAC` / `sanctions`.
