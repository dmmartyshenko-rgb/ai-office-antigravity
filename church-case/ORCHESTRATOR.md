# church-case — протокол терминального оркестратора

Для локального запуска Claude Code на компьютере заявителя (`claude` в корне репозитория).
Оркестратор ведёт дело сам: собирает, расшифровывает, проверяет, атакует и систематизирует
через субагентов `.claude/agents/church-*.md`. Заявитель задаёт цель, отвечает на вопросы,
переслушивает цитаты, подписывает и отправляет. Правила — `CLAUDE.md`, роли — `AGENTS.md`.

## Цель, которую оркестратор держит
Дело, которое **устоит**: каждый пункт обвинения опирается на A/B или на ≥2 независимых
источника A–C, пережил red team без `breaks`, подан в орган, властный решать, по процедуре,
которую нельзя оспорить. Оркестратор не подбирает факты под вердикт: он выясняет, что
доказуемо, и честно выводит из обвинения то, что не доказуемо.

## Старт каждой сессии
1. Прочитать `private/LEAD.md`, `private/ДОСЬЕ.md` (единственный источник правды), `CLAUDE.md`.
2. `git status` — убедиться, что `private/` не отслеживается.
3. Проверить входящие: `private/inbox/`, папку inbox на Google Диске (если подключён),
   папки на компьютере, названные в LEAD.md. Обработать пакеты по LEAD.md.
4. Если в `private/` есть документ органа (дело возбуждено) — все шаги работают на его основания и срок; внутренний гриф соблюдается буквально.
5. Собрать план из раздела «План действий» досье: открытые задачи с приоритетом,
   которые агент может выполнить сам, — в работу; остальное — в список вопросов заявителю.

## Цикл (повторять до критерия «готово»)
| Шаг | Субагент | Выход |
|---|---|---|
| Сбор | `church-collector` (параллельно по источникам: компьютер, Диск, веб) | файлы в `private/raw/`, записи в `manifest.json` |
| Расшифровка | `church-transcriber` | `work/transcripts/`, список «к переслушиванию» |
| Проверка первоисточников | `church-verifier` | `work/sources.json`, снимки `capture_web` |
| Нормы и процедура | `church-canonist` | `work/jurisdiction.md` |
| Эпизоды | `church-analyst` | `episodes/E-NNN.json`, `check_case.py` |
| Представление или ходатайство | `church-drafter`: если орган **уже возбудил дело** — ходатайство о приобщении строго под основания органа (`templates/hodataistvo.md`, `procedure/stages.md`); иначе — представление | `drafts/predstavlenie.md` / `drafts/hodataistvo.md` |
| Атака | `church-defense` (не видит рассуждений составителя) | `drafts/redteam.md` |
| Вердикт | `church-judge` | «готово» / блокеры |
| Мотив и роль | `church-motive` | замечания заявителю |

После каждого шага: обновить ДОСЬЕ.md (факты с уровнем, реестр, задачи, журнал; копия `.bak`
перед перезаписью). Независимые задачи сбора запускать параллельно, в фоне.
Цикл 6↔7 повторяется, пока в обвинении остаётся `breaks`.

## Браузер
`scripts/capture_web.py` — единственный способ брать веб-страницу в дело (снимок + HTML +
текст + sha256 + UTC-время). Для страниц за логином — `--profile` с отдельным профилем,
куда заявитель сам вошёл. Агент в браузере только читает. Если нужен интерактивный
просмотр (поиск по стене, прокрутка), результат всё равно фиксируется `capture_web`.

## Шлюзы — агент останавливается и спрашивает заявителя
- любое сообщение, письмо, жалоба, пост, звонок — наружу уходит только от заявителя и после его «да»;
- контакт со свидетелями и должностными лицами — только заявитель; агент готовит вопросы;
- использование записи разговора с третьим лицом как доказательства — только с его согласия;
- любой эпизод с политикой, войной, армией, спецслужбами — `legal_risk_reviewed` юристом;
- противоречие в данных — «⚠ противоречие» в досье и вопрос, не выбор агента;
- роль заявителя в процедуре (член органа, автор решения органа) — решение заявителя,
  с предупреждением `church-motive`;
- коммит: показать `git status`; в git — только механизм, `private/` никогда.

## Критерий «готово» к подписи
- `check_case.py --strict` без FAIL;
- в `redteam.md` нет `breaks` по пунктам обвинения;
- юрисдикция и процедура подтверждены документом уровня A, отвод Ответчика обоснован;
- все цитаты переслушаны (`quote_checked_by_ear`), снимки веб-страниц с sha256;
- порядок Мф 18 зафиксирован письменно;
- `church-motive` пройден, юрист вычитал.
