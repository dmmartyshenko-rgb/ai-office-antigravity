# ЖКХ-Агент — правозащитный харнес на базе Claude Code

Автономная локальная система для защиты прав собственника помещения в МКД во
взаимодействии с управляющей компанией (УК): проверка начислений ЖКУ, подготовка
претензий/жалоб/исков, мониторинг тарифов и законодательства.

Принцип: **Humans steer. Agents execute.** Модель — лошадь, харнес — упряжка.
Ничего не отправляется наружу без явного одобрения человека.

> ⚠️ Инструмент подготовки и систематизации, **не замена** квалифицированной
> юридической помощи. Итоговые документы проверяет и подписывает человек.

## Структура

```
CLAUDE.md              Долговременная память: правила + нормативка РФ + форматирование
AGENTS.md              Карта процессов, ветки классификации, промпты субагентов
claude-progress.md     Трекинг задач (антидрейф целей)
scripts/
  classify_input.py    Паттерн Classify-and-act — сортировка входящих
  verify_invoice.py    Паттерн Loop-until-done — сверка квитанции с тарифами
  monitor_tariffs.py   Мониторинг тарифов/НПА → обновление tariffs.json
  send_for_approval.py Human-in-the-Loop шлюз исходящих
data/
  tariffs.json         База официальных тарифов региона (ЗАПОЛНИТЬ реальными)
  sources.json         Источники для мониторинга (ЗАПОЛНИТЬ URL РЭК/ГИС ЖКХ)
  inbox/               Входящие на разбор
  invoices/            Квитанции для аудита (+ example-2025-07.json)
  outbox/              Черновики исходящих, ожидающие согласования
templates/
  pretenzia.md         Шаблон досудебной претензии
  isk.md               Шаблон искового заявления
```

## Быстрый старт

```bash
# 1. Классифицировать входящий документ
python3 scripts/classify_input.py data/inbox/notice.txt

# 2. Проверить квитанцию на переплаты (пример)
python3 scripts/verify_invoice.py data/invoices/example-2025-07.json

# 3. Проверить источники мониторинга (после заполнения data/sources.json)
python3 scripts/monitor_tariffs.py --check-only

# 4. Поставить готовый документ на согласование человеку
python3 scripts/send_for_approval.py submit --file draft.md \
    --to "УК «Пример», ИНН 0000000000" \
    --subject "Претензия по переплате" \
    --requirements "Перерасчёт; ответ в 10 дней" --verified
python3 scripts/send_for_approval.py review <id>
python3 scripts/send_for_approval.py approve <id> --by "Иванов И.И."
```

## Что заполнить под себя

1. `data/tariffs.json` — реальные тарифы вашего региона (РЭК) и данные из
   протоколов ОСС (для «содержание/управление» и доп. услуг).
2. `data/sources.json` — URL сайта РЭК региона и ГИС ЖКХ для мониторинга.
3. `CLAUDE.md` §0 — при необходимости уточнить регион/дом.

## Зависимости

Скрипты работают на чистой стандартной библиотеке Python 3.9+.
Опционально (для PDF/фото и мониторинга) — см. `requirements.txt`.

## Рабочий цикл (pipeline)

`classify_input` → (`verify_invoice` | подготовка ответа) →
**состязательная проверка** (Агент №1 ↔ Агент №2, AGENTS.md §4) →
`send_for_approval` → отправка человеком вручную.
