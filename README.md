# AI Office Antigravity

Рабочая среда с главным агентом **Hermes** и трёхслойной мегакартой —
внешней памятью для всех разработок и научных поисков.

Философия: **Humans steer. Agents execute.** Разработки не обязаны умещаться
в поле сознания — их помнит карта; в голове держится один экран.

## Hermes — главный агент

Hermes (он же «Майк», «Марк», «Гермес») принимает задание, проектирует под него
харнес (план, проверки, критерий «готово») и исполняет конвейером
Архитектор → Разработчик → Прокурор-Валидатор. Перед задачей читает мегакарту,
после — обновляет её.

Вызов в сессии Claude Code с этим репозиторием:

- `/hermes <задание>` — напрямую как скилл;
- «Позови Майка» / «Позови Гермеса» + задание — обычной фразой;
- как субагент: Agent tool с `subagent_type: hermes`.

Определения: `.claude/skills/hermes/SKILL.md` (полный протокол),
`.claude/agents/hermes.md` (компактная версия для субагента).

## Мегакарта — три слоя

| Слой | Где | Что | Вопрос, на который отвечает |
|---|---|---|---|
| 1 | `map/INDEX.md` | Карта карт, один экран | Что у меня вообще есть? |
| 2 | `map/domains/*.md` | Снимок состояния каждого домена | Где я и что дальше? |
| 3 | `map/journal/*.md` | Append-only журнал решений | Как я сюда пришёл? |

Протокол ведения — `.claude/skills/megamap/SKILL.md` (вызов: `/megamap`).
Проверка целостности — `python3 scripts/check_map.py`.

Начинать любую сессию — с чтения `map/INDEX.md`.
