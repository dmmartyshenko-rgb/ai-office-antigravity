# AI Office Antigravity

Рабочая среда с главным агентом **Hermes**.

## Как позвать Майка

Hermes (он же «Майк», «Марк», «Гермес») — главный агент: принимает задание,
проектирует под него харнес (план, проверки, критерий «готово») и исполняет
конвейером Архитектор → Разработчик → Прокурор-Валидатор.

Вызов в сессии Claude Code с этим репозиторием:

- `/hermes <задание>` — напрямую как скилл;
- «Позови Майка» / «Позови Гермеса» + задание — обычной фразой;
- как субагент: Agent tool с `subagent_type: hermes`.

Определения:

- `.claude/skills/hermes/SKILL.md` — полный протокол главного агента;
- `.claude/agents/hermes.md` — компактная версия для запуска субагентом.
