# Задание для NotebookLM: лакшери-презентация «Трёхслойное мегакартирование»

## Как использовать (3 шага)

1. Откройте [notebooklm.google.com](https://notebooklm.google.com) → **Create new**
   (новый блокнот) → загрузите как источник файл `megamap-source.md`
   (лежит рядом с этим файлом).
2. В панели Studio выберите **Video Overview** (видео-презентация).
   Нажмите **Customize** (настроить) — и вставьте промпт из блока ниже целиком.
3. Сгенерируйте. Если стиль не попал с первого раза — перегенерируйте,
   промпт можно не менять: NotebookLM даёт заметный разброс между попытками.

> Альтернатива: тот же промпт работает и для **Audio Overview**, если нужен
> подкаст-разбор системы вместо слайдов.

## Промпт для вставки в Customize

```text
Сделай презентацию на русском языке строго по загруженному источнику.

АУДИТОРИЯ: автор системы — человек с множеством параллельных разработок и
научных поисков. Он должен ГЛУБОКО ПОНЯТЬ принцип работы и философию системы,
а не получить пересказ. Тон: уверенный, спокойный, премиальный. Без воды,
без канцелярита, без восторженных междометий.

СТИЛЬ ОФОРМЛЕНИЯ — luxury-минимализм:
- тёмный фон (глубокий графит / почти чёрный), акценты цвета шампанского
  золота, много воздуха;
- одна мысль на слайд, крупная типографика, короткие фразы вместо абзацев;
- схемы вместо списков везде, где можно: пирамида из трёх слоёв — главный
  визуальный образ, он должен появиться и повторяться;
- никакого клипарта, эмодзи и пёстрых иллюстраций.

СТРУКТУРА (12 слайдов, порядок обязателен):
1. Титул: «Трёхслойное мегакартирование» + фраза «Карта помнит всё.
   В голове — один экран».
2. Проблема: сознание не масштабируется (симптомы из раздела 1 источника).
3. Ключевой сдвиг: разработки и НЕ ДОЛЖНЫ умещаться в поле сознания.
4. Философия, 4 принципа (раздел 2): Humans steer / один экран /
   система > промпты / ничего не удаляется.
5. Пирамида трёх слоёв — общая схема с вопросом каждого слоя.
6. Слой 1 — индекс: один экран навсегда.
7. Слой 2 — карты доменов: снимок «где я и что дальше».
8. Слой 3 — журналы: append-only история «почему я так решил».
9. Главный инвариант: верхний слой не растёт — система масштабируется
   на сотню направлений при постоянной нагрузке на сознание.
10. Хранитель карты — агент Hermes: читает карту до задачи, обновляет после,
    «готово» только с зелёной проверкой целостности.
11. Живой пример: 5 реальных доменов среды (раздел 6), подчеркнуть паузы
    с зафиксированным следующим шагом.
12. Финал: метафора капитана и атласа + итог одной фразой из раздела 8.

ЗАПРЕЩЕНО: добавлять факты не из источника, англицизмы там, где есть русское
слово, слайды-простыни текста.
```

## Критерий «готово»

Презентация принята, если по ней, не открывая репозиторий, можно ответить:
(1) на какой вопрос отвечает каждый из трёх слоёв; (2) почему индекс никогда
не растёт и что это даёт; (3) что делает Hermes до и после каждой задачи.
Не отвечает — перегенерировать или ужесточить промпт.
