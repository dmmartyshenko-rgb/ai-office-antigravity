# Журнал: hermes-core

## 2026-09-03 — Контракт H-DHO-2026 вжит в протокол
Пользователь передал «HERMES SYSTEM CONTRACT: DYNAMIC HARNESS ORCHESTRATION
(H-DHO-2026)». Интегрирован выборочно, не дословно: принято — state-hole
detection, трёхуровневый каскад проверок (статика → поведение → дельта
состояния), цикл автокоррекции с лимитами (4 итерации, repetition guard,
эскалация с сохранением состояния в журнал), log snipping, маршрутизация
моделей для субагентов, пост-мортем как обязательный шаг. Адаптировано —
бюджет в центах → бюджет в итерациях, Harness.json → секция харнеса в плане.
Отклонено — управление prefix-кэшем (не в руках агента в Claude Code),
универсальные команды pylint/pytest, глобальный запрет any/unknown.
Исходник и полная таблица решений: `docs/contracts/hermes-h-dho-2026.md`.
