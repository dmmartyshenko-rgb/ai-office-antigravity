# Журнал: church-case

## 2026-09-23 — Домен создан, каркас харнеса построен
Запрос: харнес внутрицерковного расследования с целью лишения сана +
атака позиции от лица Ответчика до подачи. Решения:
- Цель переформулирована с «лишить сана» на «подать доказуемое в
  компетентный орган»: заданный заранее вердикт — главная уязвимость
  дела и перед церковным органом, и в суде по ст. 152 ГК РФ.
- Материалы — вне git (репозиторий публичный: публикация = распространение).
- Валидатор сверяет каждую цитату с исходником по sha256 — защита от
  искажений расшифровки и от собственного желания «усилить».
- Третьи лица (родственники, подчинённые) — только контекст, не обвинение.
- Политика — отдельный контур риска для заявителя.
- Первая находка ресерча: вопрос юрисдикции открыт (заявленный выход
  Ответчика из прежней организации в 2017 г.) — стадия 0 процедуры.
