## 2026-08-29 — Система реализована по ТЗ и покрыта тестами
- Сделано: каталог `hermes-megamap/` — структура хранилища, CLAUDE.md-контракт,
  CLI (add-raw/consolidate/status + init/decay/lint), метаболический пайплайн
  `metabolism.py` (Triage/Consolidate/Decay&Audit, SQLite entries/edges/audit_log),
  линтер `lint_megamap.py`, тестовый сценарий `test_scenario.py` (23 проверки, PASS).
- Решение: система живёт в подкаталоге, а не в корне репо — в корне уже есть
  мегакарта среды `map/`; корень системы определяется по `.hermes/`, поэтому
  каталог переносим в отдельный репозиторий без правок.
- Решение: consolidate детерминирован (директивы `@домен`, `@new-project`,
  `@new-contact` + gravity-эвристика по упоминаниям); заметки без однозначной
  привязки остаются в буфере со статусом unmatched — ноль тихих потерь.
- Решение: два прохода consolidate (сначала `@new-*`) — иначе заметка о встрече,
  пришедшая в ту же секунду, не находила свежесоздаваемый домен (поймано тестом).
