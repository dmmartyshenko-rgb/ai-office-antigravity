# Журнал: rezonans

## 2026-09-05 — Паспорт получен, домен заполнен
Из другого чата с Claude получен паспорт проекта (сохранён:
docs/projects/rezonans-passport.md). Ключевые решения, принятые там,
и их причины:
1. Спор не о весах, а о нормализации: способ приведения каналов к 0–100
   влияет сильнее весов; при линейной нормализации стриминг подавляет всё.
2. Ранговая агрегация (медиана/Борда) вместо взвешенной суммы — снимает
   проблему нормализации, веса перестают быть решающими.
3. Публиковать тир, а не место: разница мест меньше погрешности.
4. Легитимация процедурой, а не составом: предрегистрация правил,
   воспроизводимость, независимый пересчёт, антигудхарт-протокол.
5. Первым — пилот-проверка, не пилот-демо: топ-200 на архиве восемью
   схемами, опубликовать ранговые корреляции; закрывает «а судьи кто»
   арифметически, стоит недели, не требует API.
6. Инструмент — Claude Code; роли харнисса по сессиям, судья — с чистого
   контекста (иначе засчитывает из вежливости).
7. Ссылка на Billboard как прецедент не работает: в ядре Hot 100 нет
   экспертных весов — скопирована часть, не дающая защиты.
Главный незакрытый вопрос — форма участия (5 вариантов, выбор не сделан);
он важнее методологических.

## 2026-09-05 — Домен заведён
По запросу пользователя («заведи домен на проект резонанс») зарегистрирован
домен для проекта «Резонанс». Содержание проекта не раскрыто — домен создан
как точка сборки с зафиксированным следующим шагом: пользователь описывает
замысел одним абзацем, после чего заполняются цель, ветка и артефакты.
