# Журнал: telegram-bridge

## 2026-09-18 — Домен создан, код моста написан и проверен локально
Задача: постоянный Telegram-мост на netcup. Из облачной сессии SSH на сервер
недоступен (наружу только HTTPS-прокси), поэтому сделан полный комплект для
развёртывания одной командой. Локально проверено без сессии Telegram: 401 без
токена на всех эндпоинтах, /health → authorized:false, остальные → 503,
аудит-лог пишется. Решения: StringSession в файле (не в .env), таймаут 20с на
connect при старте (сервис поднимается даже без сети до Telegram), ufw +
напоминание про облачный firewall netcup.

## 2026-09-18 — Деплой сведён к веб-консоли netcup (без SSH)
Из облачной сессии до сервера SSH закрыт, до Мака владельца прямого канала нет
(ListAgents пусто). Чтобы не гонять владельца курьером между четырьмя Клодами,
сделан bootstrap.sh: запускается двумя строками в веб-консоли netcup (root по
паролю, браузер, без ключей), сам клонирует/ставит/логинит/проверяет и печатает
BASE_URL+TOKEN. Фаервол по требованию сужен до 22 и 443; Caddy берёт сертификат
через 443 (TLS-ALPN-01, disable_http_challenge), порт 80 больше не нужен.

## 2026-09-19 — Развёрнут на сервере, приёмка 5/5
Деплой довёл терминальный Claude Code на Маке владельца (облачная сессия до
сервера не дотягивается — порт 22 закрыт). Путь доступа оказался нетривиальным:
сервер переставлен (сменился host key), забыта парольная фраза ключа (поднялась
из macOS Keychain через ssh-add --apple-load-keychain), ключа не было на новом
сервере → включили пароль через веб-консоль netcup, агент зашёл и добил.
Отдельно чинили Claude Code на Маке: он был завёрнут на мёртвый LiteLLM-прокси
(ANTHROPIC_BASE_URL/LITELLM_PROXY_KEY) — unset вернул прямой доступ к Anthropic.
Грабли на сервере: права на ключ репо Caddy; лимит Let's Encrypt на общем
goodsrv.de → ZeroSSL + таймер порта 80. Приёмка 5/5. Правки в ветке: install.sh
не перезаписывает кастомный Caddyfile; README — раздел «Известные грабли».
Открытое: точные серверные юниты (Caddyfile/таймер) в репо не перенесены —
нужны файлы с сервера. LightRAG (localhost:9621) недоступен — решение туда не
записано, только сюда, в мегакарту.
