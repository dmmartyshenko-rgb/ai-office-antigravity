# route-loop — двухмодельная петля Fable + Sol

## Статус
Пауза (среда выбрана: облако; ждёт открытия сети и токена от пользователя).
Обновлено: 2026-09-06.

## Ветка
`claude/fable-sol-route-setup-ds26bw`.

## Цель
Петля сборки на двух моделях: Fable 5 — босс (интервью → план → ревью),
GPT-5.6 Sol через Codex CLI — исполнитель (пишет и чинит), цикл до аппрува Fable.

## Артефакты
- `.claude/skills/route/SKILL.md` — протокол петли (вызов: `/route`).
- `.claude/skills/route/SETUP.md` — разовая настройка Codex CLI + модели.
- `.claude/skills/route/HANDOFF.md` — формат передачи задания Sol.
- `.claude/skills/route/config.sample.toml` — образец конфигурации.

## Следующий шаг
Пользователь в настройках облачного окружения (claude.ai/code → environment):
1) в сетевой политике разрешает `api.openai.com` и `auth.openai.com`;
2) добавляет переменную окружения `OPENAI_API_KEY` с токеном.
После этого в новой/перезапущенной сессии: проверка сети, настройка Codex CLI
по SETUP.md и первый боевой прогон `/route` с брифом
`docs/research/contact-mapping-build-brief.md`.

## Риски / открытые вопросы
- Решение 2026-09-06: среда — облако (заменяет выбор «Mac» от 2026-08-30).
- Проверено 2026-09-06: сеть ещё закрыта (CONNECT 403), `OPENAI_API_KEY`
  в env не виден — блокер снимается только настройками окружения,
  из сессии его не снять.
- Изменения окружения подхватываются новым контейнером — после правки
  настроек может понадобиться новая сессия.
- Стоимость/доступность GPT-5.6 Sol во внешнем API не проверялась.
