# hermes-core — главный агент Hermes

## Статус
Активен. Обновлено: 2026-08-29.

## Ветка
`claude/hermes-three-layer-megamapping-nre9qg` (актуальная версия с мегакартой);
исходная версия — `claude/pozovi-majka-xiehvj`.

## Цель
Главный агент среды: принимает любое задание, проектирует харнес (план, проверки,
критерий «готово»), исполняет конвейером Архитектор → Разработчик →
Прокурор-Валидатор, ведёт мегакарту как внешнюю память пользователя.

## Артефакты
- `.claude/skills/hermes/SKILL.md` — полный протокол (вызов: `/hermes`, «позови
  Майка/Марка/Гермеса»).
- `.claude/agents/hermes.md` — компактная версия для запуска субагентом
  (`subagent_type: hermes`).

## Следующий шаг

поправить протокол (что оказалось лишним — выкинуть).
