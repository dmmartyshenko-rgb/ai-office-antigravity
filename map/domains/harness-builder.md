# harness-builder — скил инженера обвязки ИИ-агентов

## Статус
Активен. Обновлено: 2026-09-03.

## Ветка
`claude/harness-builder-skill-9881yz`.

## Цель
Скил Harness Engineer: по команде `@harness-builder` / `/harness-builder`
генерировать детерминированную обвязку (харнес) для ИИ-агентов — лимиты, верификаторы,
цикл самокоррекции Constrain → Inform → Verify → Correct, 4-слойная память —
вместо «мягких» просьб в промптах.

## Артефакты
- `.claude/skills/harness-builder/SKILL.md` — полная спецификация: 4 слоя + 6 столпов,
  4-шаговый протокол (Analyze → Verify → Correct & Constrain → Memory), шаблон
  `SafeAgentOrchestrator` на Python, few-shot примеры.

## Следующий шаг
Обкатать скил на реальном проекте (кандидаты: mimo-bot, zhkh-agent) — сгенерировать
для него verifier + оркестратор и проверить цикл самокоррекции вживую.

## Риски / открытые вопросы
- Шаблон оркестратора — эскиз: цены в `_track_cost` и имя модели надо сверять с
  актуальным прайсом при каждом применении.
- Пересечение зон с Hermes: Hermes — харнес процесса (роли, план), harness-builder —
  харнес как код (рантайм). Граница описана в SKILL.md, но может размыться на практике.
