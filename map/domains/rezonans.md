# rezonans — проект «Резонанс» (индекс музыкального спроса)

## Статус
Активен (стадия: методологическая работа; форма участия не выбрана).
Обновлено: 2026-09-05.

## Ветка
`main`: паспорт — `docs/projects/rezonans-passport.md` (первоисточник, из
чата с Claude). Рабочая папка методологии разворачивается в Claude Code по
отдельному промту настройки — вне этого репозитория. Входные материалы —
Telegram-переписка от 25 июля и сентябрьская рассылка.

## Цель
Двухуровневая:
- **Рабочая (моя, текущая):** методология расчёта индекса, выдерживающая
  проверку индустриальными скептиками. Роль — внешний методолог-рецензент,
  не операционный контур.
- **Открытый вопрос №1 (важнее пункта паспорта):** форма участия не выбрана —
  обсуждались прототип индекса, внешний методолог/ring-fence, генподряд
  «ИИнтеграции», учредительство в АНО, образовательный контур через школу ИИ.

Проект в целом: национальный индекс музыкального спроса РФ (0–100 по артисту
из стриминга, эфира, соцсетей, концертов), поверх — рейтинг, портал, премия.
Модель «нейтральный измеритель + витрина» (аналогия Luminate / Billboard).
Оформляется как АНО, гендиректор — Кристина Попельнюк.

## Артефакты
- `docs/projects/rezonans-passport.md` — паспорт проекта (полная картина).
- Вне репозитория: рецензия на июльский пакет; разбор через оптику ОДИ;
  «Методология: критика и конструкция»; харнис проверки методологии;
  CLAUDE.md + промт настройки рабочей папки Claude Code.

## Следующий шаг
Развернуть рабочую папку в Claude Code по промту настройки и прогнать
`sensitivity.py` на синтетическом примере — убедиться, что расчёт корреляций
работает и вывод читаем, до появления реальных данных.

## Риски / открытые вопросы
- **Методология:** нормализация не выбрана; атрибуция фитов/коллабораций
  отсутствует; период без поправки на возраст релиза; концерты вне ядра;
  закон Гудхарта при превращении индекса в основу премии и бюджетов.
- **Конструкция:** методсовет из тех, кого считают; АНО сняло разделение
  контуров ДАННЫЕ/ПРЕМИЯ; «партнёры» без соглашений; цепочка поставки
  данных Luminate в РФ отсутствует.
- **Моя позиция:** документарного основания на долю нет (июльские 5–8% на
  двоих с Кириллом не подтверждены, в сентябрьском концепте роли генподрядчика
  нет); отношения с Кириллом на паузе — статус «ИИнтеграции» решается через него.
- **Проверить до выноса наружу:** коэффициенты Billboard/Luminate; данные
  Mediascope по радио; ARPU российских стримингов; правовой статус
  использования публичных чартов в коммерческом продукте.

## Связи
- `iintegration` — единственная твёрдая точка входа: участие идёт через неё
  либо не идёт вовсе.
- Школа ИИ — возможный отдельный контур (обучение команды движка); своего
  домена пока нет, заводить при первом реальном шаге.
