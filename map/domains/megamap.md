# megamap — трёхслойное мегакартирование

## Статус
Активен. Обновлено: 2026-08-29.

## Ветка
`main` (карта видна в каждой сессии); разработка велась на
`claude/hermes-three-layer-megamapping-nre9qg`.

## Цель
Внешняя память среды: все разработки и научные поиски пользователя учтены в
карте из трёх слоёв (индекс → карты доменов → журналы), так что в голове и в
контексте сессии достаточно держать один экран — слой 1.

## Артефакты
- `.claude/skills/megamap/SKILL.md` — протокол трёх слоёв (вызов: `/megamap`).
- `map/INDEX.md` — слой 1, карта карт.
- `map/domains/*.md` — слой 2, снимки состояния доменов.
- `map/journal/*.md` — слой 3, append-only журналы решений.
- `scripts/check_map.py` — проверка целостности карты.
- `docs/notebooklm/megamap-source.md` — самодостаточное описание системы
  (источник для NotebookLM).
- `docs/notebooklm/megamap-task.md` — задание для NotebookLM: лакшери-презентация
  системы (инструкция + промпт + критерий приёмки).
- `docs/presentation/megamap.html` — готовая лакшери-презентация (12 слайдов,
  собрана Claude; опубликована артефактом в сессии).

## Следующий шаг
Регистрировать научные поиски вне git (статьи, эксперименты, внешние
ресурсы) как домены с указанием внешнего местоположения в разделе «Ветка».

## Риски / открытые вопросы
- Порог «один экран» для INDEX задан как 60 строк — цифра на обкатку.
- Ветки-доноры (mimo-bot, zhkh-agent, route-loop) в `main` не влиты — их код
  по-прежнему живёт на своих ветках, карта лишь ссылается на них.
